# 🍔 EatMate - Swiggy Clone

EatMate is a fully functional **Swiggy-like food ordering web app** built with **React**. It allows users to browse restaurants, view dishes, add items to the cart, and place orders. The app supports **light/dark mode**, is **responsive**, and is optimized for performance.

---

## 🔥 Features

- Browse restaurants and dishes (Pizza, Burger, etc.)  
- View **dish details** on a separate page  
- **Cart functionality** with item selection and order placement  
- **Light mode & Dark mode** toggle  
- Responsive UI for **desktop and mobile**  
- Uses **live Swiggy API** for real data  
- Optimized with **Lazy Loading** and **React Suspense**  
- Built with a mix of **functional & class-based components**  
- State management using **Context API** & **Redux**  
- Tested components using **Jest** & **React Testing Library**  

---

## 🛠 Tech Stack

- **Frontend:** React (Parcel bundler), Tailwind CSS  
- **State Management:** Redux, Context API  
- **Routing:** React Router  
- **Testing:** Jest, React Testing Library  
- **Optimization:** Lazy Loading, Suspense  
- **API:** Live Swiggy API
